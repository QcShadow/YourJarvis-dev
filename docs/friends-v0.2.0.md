# 朋友版 v0.2.0

从 v0.1.6 的干净快照选取两组已经有回归验证的开发版改进。

1. 模型选择一致：主页面选中的对话模型成为默认模型，语音同步使用；选择器排除嵌入、写作及语音等非对话模型。本地预加载、自动路由和模型管理通过本安装目录的 Ollama 服务，修正动态端口导致的重启误报。
2. 语音交互：唤醒时异步预热已安装的中文播报模型，详细回答在首个完整句子后即可开始播报；改善长句停顿和轻声句尾的识别，显示模型路由、首字、开口及整轮耗时。

已有文字、Piper 和音色库继续使用原资源。无新依赖、模型下载或远程主机功能。音色训练工具、功能子智能体、图像生成和独立写作工作区保持开发状态，不包含在此版本中。

预热不能消除 CPU 模型冷启动时间，也不承诺所有配置实时播报。语音时长与等待显示使用当前回合的实际测量值。

兼容修复：在中文安装目录里使用相对的 eSpeak 数据路径，使已有 Piper 音色可正常播报，避免原生库回退到打包机器的失效路径。

发布验证应涵盖前后端回归、生产构建、安装包大小及 SHA-256、中文带空格目录安装、轻量 CPU 模型实际聊天与预加载、旧版覆盖升级并保留用户配置与音色。
