# Windows friend installer 0.1.3

The single EXE contains the program ZIP and opens the native Chinese wizard.
Its immutable resources.json pins size and SHA-256 for every resource part and
complete archive. Gitee is first, GitHub is fallback; a 30-second idle timeout
avoids indefinitely stuck streams. Range requests resume identical pinned bytes.

Gitee quotas require separate purpose-specific repositories: main distribution
for application, lite LLM, CPU Ollama and WebView2; your-jarvis-runtime for Python
and dedicated text/voice dependency environments; your-jarvis-speech for ASR/TTS
weights. Each attachment is at most 90 MiB and each repository stays below 1 GB.
All components are also hosted in the main GitHub v0.1.3 release.

Do not copy an owner's environment: build the voice environment from a clean
source snapshot with only server/desktop/voice extras, misaki[zh] and the official
English spaCy language wheel. Runtime packs exclude console entry points, pyc,
builder pyvenv.cfg, editable paths and direct_url metadata. The native downloader
rewrites interpreter home and source .pth for the destination; scripts invoke
python -m openjarvis.cli. Keep CPython and dependency licenses/metadata.

Installation clears stale completion state, stops only an owned backend after
validating its recorded PID and executable path, performs real ASR/TTS tests
for voice selections, then starts a separate backend on a free loopback port
and verifies health, HTML and chat before recording completion.

Build from the committed source snapshot, rebuild/retain matching frontend
assets, compile launchers, and include the verified resource manifest. Verify
the extracted program manifest and run fresh installation in Chinese/space
paths with no external package/model downloads. Publish update manifests only
after every advertised attachment is available; cleanup obsolete public
releases only after the new release and downloaded checksums are verified.
