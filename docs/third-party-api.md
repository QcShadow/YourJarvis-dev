# 开发版：第三方 API

在「设置 → 模型 → 第三方 API · 补充模型来源」添加支持 OpenAI 协议的服务。

1. 填写自定义名称，例如「中科大」。聊天模型列表会显示「名称 / 模型 ID」。
2. 填写接口地址、该服务的 API Key 和实际提供的模型 ID（每行一个）。
   地址支持根地址、带 `/v1` 的地址或完整的 `/v1/chat/completions` 地址，
   也支持带路径前缀的网关。
3. 点击「测试连接并读取模型」。这会向第一行模型发送一次短请求；
   若服务支持 `/v1/models`，还会显示可添加的模型。
4. 启用并保存，重启 JARVIS 后端后，在聊天中选择对应名称的模型。

例如学校平台可以自定义命名为「中科大」，地址填写
`https://api.llm.ustc.edu.cn`，模型 ID 使用平台提供的名称，例如 `qwen-chat`。

保存后原来的默认模型和接口仍可使用。改名只改变展示，内部模型 ID
固定使用 `third-party/` 前缀；发给服务平台时会去掉这一前缀。
显式选择第三方模型时，本地自动路由不会覆盖这一选择。
密钥独立存储于本机凭据文件的 `third_party_api` 分组。
更换接口地址时需填写对应密钥；原服务的密钥不会用于测试新地址。
此前开发版的专用配置和密钥会自动读取，首次通过新界面保存后迁移为通用配置。

```toml
[engine.third_party_api]
enabled = true
name = "中科大"
host = "https://api.llm.ustc.edu.cn"
models = ["qwen-chat"]
```

也可使用 `THIRD_PARTY_API_KEY` 环境变量提供密钥。
工具调用采用 OpenAI `tools` / `tool_calls` 协议，实际能力由所选模型决定。
此功能已在开发版源码及本地前端实现，分享版发布包尚未更新。
