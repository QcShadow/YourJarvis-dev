# JARVIS Link

> 此文档描述早期精简文字原型。当前分发版本已改为复用完整 JARVIS 界面的离线客户端，使用 `build_full_package.py` 构建；详见 `README-Full.zh-CN.md` 和 `DEPENDENCIES-Full.zh-CN.md`。

独立的轻量客户端，使用与 JARVIS 开发版同源的配色。解压到自己的可写目录，双击 `JARVIS-Link.exe` 或 `打开JARVIS-Link.cmd`。

首页提供两种使用方式：

- **本机轻量模型**：随包提供 Qwen2.5 0.5B、CPU Ollama、WebView2 固定运行时。点击即开始，无需下载依赖、模型、Python 或 Ollama，不需要独立显卡。中文文字建议整机 4 GB 内存起，8 GB 更舒适；这是容量估算，小模型适合短对话。
- **共享模型服务**：填写主机地址和邀请令牌。计算由主机承担，只需要访问该地址，不需要能访问海外模型网站。当前通过 JARVIS 的独立 friends 网关连接。

浅色／深色和 MCU Jarvis、Codex、Claude 等配色直接取自开发版的 palette 定义，构建时同步。首页、聊天页、原生标题栏使用同一组颜色。界面不展示“朋友版”这一内部代称。

## 完全离线的本机使用

支持 Windows 10 22H2 / Windows 11 x64，需系统自带 .NET Framework 4.8。WebView2 已附带，无需系统预装 Edge 或 WebView2，也不会在首次启动运行安装器。不要放在 Program Files、只读目录、网络共享目录；不要只复制 exe。

本机模型通过独立随机回环端口运行，不连接开发版 8000 / 11434，也不读取开发版的 config、密钥或私人记忆。聊天仅保留在当前页面，关闭后清空。关闭窗口会停止这份应用启动的 Ollama 和模型进程，保留包内模型供下次使用。当前只提供文字，未包含本地语音。

如果包内文件缺失，应用会提示重新解压，而不会尝试联网补齐。是否需要外网、各项依赖与构建来源详见“联网与依赖清单.md”。

## 使用共享主机

主机主人启动独立 `jarvis friends serve` 并提供 HTTPS / Tailscale Serve 地址，以及每人独立的 `jf_...` 令牌。请填写共享服务地址，不要填写私人助手页面或 Ollama API 地址。本机、私有 IPv4 局域网测试可使用 HTTP，例如 `http://127.0.0.1:8001`。

地址会保留供下次填写，令牌不会保存，重开时重新输入。网关提供邀请验证、撤销、排队和速率限制，聊天不访问主人的私人记忆、文件或桌面工具；主机作为处理方仍能接触推理数据。主机的部署步骤见开发目录的“分享与部署说明.md”。

## 复制给其他人

请使用发布的干净 ZIP；运行过的目录会产生本机 `data`、`logs`，不要直接把这些状态发给其他人。ZIP 不含个人数据、API 密钥、邀请令牌或私人配置，旁边有 `.sha256` 校验文件，包内含逐文件摘要清单。

本版是便携包，不写入系统启动项、不修改防火墙、不开放公网端口。固定 WebView2 由制作者随新版软件更新。
