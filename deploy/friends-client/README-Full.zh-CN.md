# JARVIS Link 完整客户端

此版本直接使用开发版同一套完整前端和后端。侧栏、聊天历史、语音、角色、记忆、工具、Agent、技能、模型调度和全部设置入口均保留。区别在默认模型与各用户自己的配置、数据。

解压到可写目录，双击 `JARVIS-Link.exe` 或 `打开JARVIS-Link.cmd`。不要在压缩包内运行。无需安装 Python、Node、Ollama，也无需第一次启动下载依赖。默认 Qwen2.5 0.5B CPU + SenseVoice 中文识别 + Kokoro 云健/晓晓；同时包含 Whisper small.en 和英语 George。文本、语音及常用本地工具可离线使用。

模型很小，因此复杂推理、长对话和自主工具调用质量有限；这不会隐藏或关闭软件功能。设置 → 模型与首次配置预设可切换：

- 轻量中文：使用包内 Qwen2.5 0.5B。
- 已有 Ollama 模型：填写自己的模型和服务地址。
- 连接 JARVIS 远程主机：填写共享入口（例如 `http://主机局域网地址:8001/v1`），模型 ID 留作 `host-model`，填写邀请令牌。
- LLM API：填写 OpenAI 兼容地址、模型 ID 和密钥。

先保存，再点击「应用并重启模型服务」。重启服务保留聊天和其他配置。远程主机离线时，设置界面仍可打开，以便切回本地模型。

远程模式：主机只进行模型推理，工具在使用者电脑执行，记忆属于使用者。发给模型的对话、选中的文件内容、工具结果会传给该模型服务。不会把主机主人的私人 UI、文件或记忆开放给使用者。

最低系统：Windows 10 22H2 / Windows 11 x64，.NET Framework 4.8（支持的 Windows 通常已有）。完整客户端建议 8 GB 内存起，16 GB 更舒适；预留至少 8 GB 磁盘空间，不要求独立显卡。语音首次加载会占用额外内存，速度因 CPU 而异。这是容量建议，尚未完成低内存实体电脑测试。

包内未包含大型图像生成模型、Qwen 高级声音、第三方应用和付费服务账户。相关功能和配置入口保留，使用时需自行提供资源或服务；联网搜索和远程 API 本身需要可用网络。可选扩展与离线依赖详情见「联网与依赖清单.md」。

配置/密钥/数据库在 `data/state`，桌面浏览器资料在 `data/desktop/webview2`，模型在 `models`，日志在 `logs`。主机推理入口使用 `jarvis friends invite NAME` 和 `jarvis friends serve --host 局域网地址 --port 8001`；无需开放私人后端 8000 或 Ollama 11434。跨互联网需要先配置可访问的主机地址/网络转发，本包不自动发布主机。

旧的约 752 MB 文字客户端属于早期精简原型；不要再将它当作完整 JARVIS Link 分发。
